# Proyecto 1 — Base de Datos Hospitalaria

Proyecto individual desarrollado para modelar e implementar una base de datos
para la cadena Hospitales de Occidente utilizando PostgreSQL.

## Estructura del repositorio

- `modelo/`: diseño, archivo editable e imágenes del modelo Barker.
- `sql/ddl/`: sentencias de definición de la base de datos.
- `sql/dml/`: datos ficticios utilizados para las pruebas.
- `sql/dcl/`: creación de roles y asignación de privilegios.
- `backup/`: respaldo de PostgreSQL con estructura y datos.
- `documentacion/`: documento final del proyecto en formato PDF.

## Tecnologías

- PostgreSQL 16 o superior.
- DBeaver Community Edition.
- Git y GitHub.
